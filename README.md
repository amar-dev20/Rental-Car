# 🚗 RentalCar - Car Rental Website

A full-stack car rental web application that allows users to explore available cars, book vehicles, and manage their bookings. The platform also provides owner features for managing cars and reservations.

##  👉 Live Preview

> link: https://rental-car-eta-bay.vercel.app/

## ✨ Features

- 🔐 User authentication and authorization
- 🚘 Browse available rental cars
- 🔎 View car details
- 📅 Book cars for selected dates
- 📋 View and manage personal bookings
- 🏢 Owner dashboard
- 🚗 Add, manage, and delete cars
- 📊 Manage customer bookings
- 🖼️ Image upload and management

## 🛠️ Tech Stack

**Frontend**

- React.js

**Backend**

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/amar-dev20/Rental-Car.git

```

### 2. Navigate to the Project

```bash
cd Rental-Car

```

### 3. Install Frontend Dependencies

```bash
cd client
npm install

```

### 4. Start the Frontend

```bash
npm run dev

```

### 5. Install Backend Dependencies

Open another terminal:

```bash
cd server
npm install

```

### 6. Configure Environment Variables

Create a `.env` file inside the `server` directory and configure the variables required by your backend.

For example:

```env
PORT=3000
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret

```

Add any other required variables for your ImageKit configuration.

Never upload your actual passwords, database credentials, or API secrets to GitHub.

### 7. Start the Backend

```bash
npm run server

```

Check your `server/package.json` for the correct start script. If `npm run server` is not defined, use the appropriate script configured in that file.
